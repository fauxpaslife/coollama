# Changelog

## 0.1.0-alpha - 2026-08-01

- Added local HTTPS static server for New Outlook add-in loading.
- Added CoOllama task pane with Ollama model selection, summaries, draft replies, current-email review, spell/grammar review, suspicious-email review, and Ask Anything.
- Added Markdown preview rendering and sanitized HTML insertion for compose drafts.
- Added compose rewrite/apply support.
- Added pinning support with Outlook item-change refresh handling.
- Added light/dark theme toggle with persisted preference.
- Added sticky recent-item work state for reply notes, chat prompt, summary mode, and latest result.
- Added voice profile builder with sticky manual Sent sample workflow.
- Added installer/uninstaller scripts, Start Menu shortcut, and Startup shortcut for the local server.
- Added repo hygiene/security docs and ignored local-only screenshots/context files.
